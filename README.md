## ✨ Nima qila oladi

- **Diktovka** — istalgan ilovada tugma bosib gapiring, matn avtomatik yoziladi
  (macOS: `⌃⌥D`, Windows: `Ctrl+Alt+D`).
- **Studiya** — audio yoki video fayldan matn (transkripsiya).
- **Tarjima** — 200+ til, oflayn.
- Diktovka tarixi, matnni tozalash va sunʼiy intellekt amallari (ixtiyoriy).

## 🔒 Maxfiylik

Ovoz tanish va tarjima **sizning qurilmangizda** bajariladi. Ovoz, matn va
nima yozganingiz **hech qachon yuborilmaydi**. Ilovani yaxshilash uchun faqat
anonim texnik oʻlchovlar (qurilma turi, tezlik) yigʻiladi.

Toʻliq: [Maxfiylik siyosati](PRIVACY.md) · [uzb.mirqobilov.com/maxfiylik](https://uzb.mirqobilov.com/maxfiylik)
